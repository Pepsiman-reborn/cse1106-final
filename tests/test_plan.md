# Test Cases for Temperature Monitor
## Test 1
- When user enters a reading of 70, the program returns a status of NORMAL and the LED is not turned on
## Test 2
- When the user enters q at the menu prompt, the program ends
## Test 3
- When the user enters c at the menu prompt, they will be able to change the range for valid temperatures
## Test 4
- When the user enters an invalid command at the menu prompt, the program asks for user to reenter
## Test 5
- When the user enters 5 temperature readings, the program will end as it only accepts up to 5 readings

## ALSO
- For all test cases, before ending the program, the average temperature of the entered readings will be displayed
- It also prints the statuses to an external file
